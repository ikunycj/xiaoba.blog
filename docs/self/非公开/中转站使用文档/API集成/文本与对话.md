# 文本与对话

## Chat Completions

官方文档：[Chat Completions API](https://platform.openai.com/docs/api-reference/chat)

```http
POST /v1/chat/completions
```

```bash
curl https://alltokenapi.com/v1/chat/completions \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "your-model-id",
    "messages": [{"role":"user","content":"你好"}]
  }'
```

必填：`model`、`messages`。

常用参数：`temperature`、`top_p`、`max_tokens`、`max_completion_tokens`、`stream`、`tools`、`tool_choice`、`response_format`。

流式请求：将 `stream` 设置为 `true`，用支持 SSE 的客户端读取响应。

OpenAI SDK 的 `base_url` 填 `https://alltokenapi.com/v1`；直接请求则把完整路径写成 `https://alltokenapi.com/v1/chat/completions`。

## Responses

官方文档：[Responses API](https://platform.openai.com/docs/api-reference/responses)

```http
POST /v1/responses
```

```bash
curl https://alltokenapi.com/v1/responses \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "your-model-id",
    "input": "解释一下 API 网关",
    "instructions": "用中文简短回答"
  }'
```

必填：`model`、`input`。

常用参数：`instructions`、`max_output_tokens`、`stream`、`tools`、`tool_choice`、`reasoning`、`previous_response_id`。

Responses 与 Chat Completions 的请求体不通用；使用 Responses 时不要发送 `messages` 字段。

Responses Compact：

```http
POST /v1/responses/compact
```

仅对模型列表中明确支持该端点的 OpenAI/Codex 模型使用。

## Claude Messages

官方文档：[Anthropic Messages API](https://docs.anthropic.com/en/api/messages)

```http
POST /v1/messages
```

```bash
curl https://alltokenapi.com/v1/messages \
  -H "x-api-key: sk-your-api-key" \
  -H "anthropic-version: 2023-06-01" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "your-claude-model-id",
    "max_tokens": 512,
    "messages": [{"role":"user","content":"你好"}]
  }'
```

必填：`model`、`max_tokens`、`messages`。

Claude Code：

```text
ANTHROPIC_BASE_URL=https://alltokenapi.com
ANTHROPIC_API_KEY=sk-your-api-key
```

直接请求 Claude Messages 时，地址使用 `https://alltokenapi.com/v1/messages`，鉴权使用 `x-api-key`，不要改成 OpenAI 的 `Authorization` 请求头。

## Gemini 原生对话

官方文档：[Gemini Generate Content](https://ai.google.dev/api/generate-content)

```http
POST /v1beta/models/{model}:generateContent
```

```bash
curl https://alltokenapi.com/v1beta/models/your-gemini-model-id:generateContent \
  -H "x-goog-api-key: sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [{"role":"user","parts":[{"text":"你好"}]}]
  }'
```

必填：`contents`。流式调用将动作改为 `streamGenerateContent`，通常添加 `?alt=sse`。

Gemini 原生接口使用 `x-goog-api-key`，模型列表见[模型接口](API模型接口.md#gemini-原生接口)。它与 OpenAI 格式的 `messages` 请求体不通用。

## 传统 Completions

官方文档：[Completions API](https://platform.openai.com/docs/api-reference/completions)

```http
POST /v1/completions
```

```bash
curl https://alltokenapi.com/v1/completions \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{"model":"your-model-id","prompt":"Once upon a time","max_tokens":64}'
```

必填：`model`、`prompt`。新模型优先使用 Chat 或 Responses。
