# 查询异步视频任务

使用创建任务时返回的 `id` 查询视频生成进度。该接口只读取任务状态，不会重复创建任务或再次扣除生成费用。

## 请求

```http
GET /v1/videos/{task_id}
```

```bash
curl "https://alltokenapi.com/v1/videos/video_task_xxx" \
  -H "Authorization: Bearer sk-your-api-key"
```

将 `video_task_xxx` 替换为创建视频任务响应中的 `id`。

## 响应示例

任务正在处理：

```json
{
  "id": "video_task_xxx",
  "object": "video",
  "model": "your-video-model-id",
  "status": "in_progress",
  "progress": 45,
  "created_at": 1760000000,
  "seconds": "8"
}
```

任务已完成：

```json
{
  "id": "video_task_xxx",
  "object": "video",
  "model": "your-video-model-id",
  "status": "completed",
  "progress": 100,
  "created_at": 1760000000,
  "completed_at": 1760000048,
  "seconds": "8",
  "size": "1280x720"
}
```

任务失败：

```json
{
  "id": "video_task_xxx",
  "object": "video",
  "model": "your-video-model-id",
  "status": "failed",
  "progress": 0,
  "created_at": 1760000000,
  "error": {
    "code": "video_generation_failed",
    "message": "The upstream service could not complete the task."
  }
}
```

不同渠道返回的可选字段可能不同，客户端应以 `status` 为主要判断依据。

## 状态说明

| 状态 | 含义 | 客户端处理 |
| --- | --- | --- |
| `queued` | 任务已进入队列 | 等待后继续轮询 |
| `in_progress` | 正在生成 | 显示进度并继续轮询 |
| `completed` | 生成完成 | 停止轮询并获取视频内容 |
| `failed` | 生成失败 | 停止轮询并记录 `error` |

## 获取视频内容

当 `status` 为 `completed` 时，可以使用同一个任务 ID 获取视频文件：

```http
GET /v1/videos/{task_id}/content
```

```bash
curl -L "https://alltokenapi.com/v1/videos/video_task_xxx/content" \
  -H "Authorization: Bearer sk-your-api-key" \
  --output result.mp4
```

任务尚未完成时请求内容接口会返回错误。下载较大视频时应为客户端配置足够的超时时间。

## 轮询建议

1. 首次查询可在创建任务数秒后进行。
2. 后续轮询使用固定间隔或指数退避，例如逐步增加到 5 至 10 秒。
3. 收到 `completed` 或 `failed` 后立即停止轮询。
4. 为客户端设置总等待时限，并持久化任务 ID，避免页面刷新后丢失任务。
5. 对 `404` 不要无限重试，应检查任务 ID 是否来自当前账号和当前站点。

## 常见问题

- `404`：任务 ID 不存在，或该任务不属于当前用户。
- 长时间停留在 `queued`：上游可能排队，适当降低轮询频率后继续等待。
- `progress` 不变化：部分渠道只更新状态，不持续提供精确进度。
- `failed`：查看 `error.code` 和 `error.message`，修正输入后创建新任务。
