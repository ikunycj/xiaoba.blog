# 创建异步视频任务

视频生成通常需要较长时间。提交请求后，接口会立即返回任务 ID；客户端应保存该 ID，并通过查询接口轮询任务状态。

## 请求

```http
POST /v1/videos
```

请求体使用 `multipart/form-data`：

```bash
curl "https://alltokenapi.com/v1/videos" \
  -H "Authorization: Bearer sk-your-api-key" \
  -F "model=your-video-model-id" \
  -F "prompt=A cinematic aerial shot of a city at sunrise" \
  -F "seconds=8"
```

如果模型支持参考图，可增加 `input_reference` 文件字段：

```bash
curl "https://alltokenapi.com/v1/videos" \
  -H "Authorization: Bearer sk-your-api-key" \
  -F "model=your-video-model-id" \
  -F "prompt=The camera slowly moves toward the subject" \
  -F "seconds=8" \
  -F "input_reference=@reference.png"
```

不要手动设置 `Content-Type`。`curl -F` 会自动生成包含 boundary 的 `multipart/form-data` 请求头。

## 请求字段

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | 当前 API Key 可用的视频模型 ID |
| `prompt` | string | 是 | 视频内容、镜头运动和风格描述 |
| `seconds` | string | 否 | 生成时长，允许值取决于模型和渠道 |
| `input_reference` | file | 否 | 参考图片文件，仅在模型支持图生视频时使用 |

模型是否支持参考图、可选时长和其他能力由实际渠道决定。首次调用建议只传必需字段，确认成功后再增加参考图等可选输入。

## 响应示例

```json
{
  "id": "video_task_xxx",
  "object": "video",
  "model": "your-video-model-id",
  "status": "queued",
  "progress": 0,
  "created_at": 1760000000,
  "seconds": "8"
}
```

`id` 是本站返回的视频任务 ID。后续查询状态和获取视频内容时都应使用该值，不要改用上游任务 ID。

## 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 视频任务 ID |
| `object` | string | 对象类型，通常为 `video` |
| `model` | string | 实际使用的模型 |
| `status` | string | 当前任务状态，提交成功时通常为 `queued` |
| `progress` | integer | 进度百分比 |
| `created_at` | integer | 任务创建时间戳 |
| `seconds` | string | 视频时长 |
| `completed_at` | integer | 完成时间戳，仅完成后可能返回 |
| `size` | string | 视频尺寸，仅渠道提供时返回 |
| `error` | object | 失败信息，仅任务失败时返回 |

## 下一步

提交成功后，请调用 [`GET /v1/videos/{task_id}`](查询异步视频任务.md) 查询任务状态。轮询时应设置合理间隔，不要在短时间内连续发送大量请求。

## 常见问题

- `400`：检查 `model`、`prompt`、`seconds`，以及参考图的文件格式和大小。
- `401`：检查 `Authorization` 请求头和 API Key。
- 模型不可用：请求 `/v1/models`，确认当前 API Key 可以看到对应视频模型。
- 参考图请求失败：先移除 `input_reference` 验证纯文本生成，再确认模型支持图生视频。
