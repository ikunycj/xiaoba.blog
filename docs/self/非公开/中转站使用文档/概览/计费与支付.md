# 计费与支付

## 打开钱包

钱包会显示当前余额以及站点已启用的充值方式。管理员未配置的功能不会显示。

[打开钱包](https://alltokenapi.com/wallet)

## 在线充值

1. 打开钱包，选择可用的在线支付方式。
2. 输入不低于付款表单所示最低金额的数额。
3. 确认前检查金额和支付方式。
4. 在支付服务商页面完成付款，然后返回钱包。
5. 刷新余额，并打开账单历史验证结果。

> **支付方式因站点配置而异**
>
> 可用的支付服务商、币种、手续费和最低金额由当前站点配置决定。

## 兑换充值码

1. 在钱包页面找到兑换码区域。
2. 输入完整兑换码，不要带多余空格。
3. 只提交一次，然后等待确认消息。
4. 在余额和账单历史中验证到账金额。

启用外部购买入口时，钱包还可能显示充值码购买链接。离开本站前，请确认链接目标是否正确。

## 订阅计划

如果站点配置了订阅计划，请在购买前比较价格、有效期、可用模型和使用限制。

订阅额度和钱包余额可能使用不同的计费规则。请查看套餐详情和使用日志，不要假定两者可以互换。

## 推荐奖励

1. 从“推荐计划”卡片复制推荐链接，并通过本站允许的渠道分享。
2. 使用“待转奖励”“累计奖励”和“邀请人数”跟踪奖励与推荐活动。
3. 有待转奖励时，点击“转入余额”。
4. 输入不低于页面所示最低金额且不超过可用奖励的数额，然后确认转入。
5. 确认待转奖励减少，同时钱包余额增加。

管理员确认合规条款之前，推荐奖励转入功能不可用。

## 验证余额变化

1. 打开账单历史，找到最新交易。
2. 确认金额、状态和创建时间。
3. 发出模型请求后，将钱包余额变化与使用日志中的详细费用进行比较。

[打开使用日志](https://alltokenapi.com/usage-logs)

## 故障排查

1. 如果没有显示支付方式，站点可能未启用在线支付。
2. 如果金额被拒绝，请输入不低于所选支付方式最低金额的数额。
3. 如果付款长时间处于待处理状态，请保留支付服务商的凭证，不要立即重复付款。
4. 如果兑换码无效，请检查多余空格、是否已使用、是否过期或输入错误。
