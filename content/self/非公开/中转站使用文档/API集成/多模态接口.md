# 多模态接口

先用 `GET /v1/models` 确认模型 ID，再确认该模型支持对应能力。

## 图片

官方文档：[Images API](https://platform.openai.com/docs/api-reference/images)

生成：

```http
POST /v1/images/generations
```

```bash
curl https://alltokenapi.com/v1/images/generations \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{"model":"your-image-model-id","prompt":"一座湖边的山，日出","n":1,"size":"1024x1024"}'
```

编辑：

```http
POST /v1/images/edits
```

```bash
curl https://alltokenapi.com/v1/images/edits \
  -H "Authorization: Bearer sk-your-api-key" \
  -F "model=your-image-model-id" \
  -F "prompt=把天空改成日落" \
  -F "image=@input.png"
```

`/v1/edits` 是图片编辑兼容别名。不同图片模型可能使用不同请求体，模型详情页示例优先。

## 音频

官方文档：[Audio API](https://platform.openai.com/docs/api-reference/audio)

转写：

```bash
curl https://alltokenapi.com/v1/audio/transcriptions \
  -H "Authorization: Bearer sk-your-api-key" \
  -F "file=@audio.mp3" \
  -F "model=your-audio-model-id"
```

翻译：将路径改为 `/v1/audio/translations`。

文本转语音：

```bash
curl https://alltokenapi.com/v1/audio/speech \
  -H "Authorization: Bearer sk-your-api-key" \
  -H "Content-Type: application/json" \
  -d '{"model":"your-tts-model-id","input":"欢迎使用 API","voice":"alloy","response_format":"mp3"}' \
  --output speech.mp3
```

## Realtime

官方文档：[Realtime API](https://platform.openai.com/docs/api-reference/realtime)

```text
wss://alltokenapi.com/v1/realtime?model=your-realtime-model-id
```

浏览器不能自定义 `Authorization` 时，可在握手时传递以下子协议：

```text
Sec-WebSocket-Protocol: realtime, openai-insecure-api-key.sk-your-api-key, openai-beta.realtime-v1
```

服务端会返回 WebSocket 事件，事件格式和会话流程以 [Realtime API](https://platform.openai.com/docs/api-reference/realtime) 为准。

## 视频

官方文档：[Videos API](https://platform.openai.com/docs/api-reference/videos)

创建任务：

```bash
curl https://alltokenapi.com/v1/videos \
  -H "Authorization: Bearer sk-your-api-key" \
  -F "model=your-video-model-id" \
  -F "prompt=A cinematic sunrise over a city" \
  -F "seconds=8"
```

查询和下载：

```bash
curl https://alltokenapi.com/v1/videos/video_task_xxx \
  -H "Authorization: Bearer sk-your-api-key"

curl -L https://alltokenapi.com/v1/videos/video_task_xxx/content \
  -H "Authorization: Bearer sk-your-api-key" \
  --output result.mp4
```

只有任务状态为 `completed` 时下载内容。Kling、Midjourney、Suno 和即梦使用各自的任务接口，路径见[兼容性与限制](兼容性与限制.md)。
