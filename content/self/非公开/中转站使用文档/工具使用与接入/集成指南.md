将 AllTokenAPI 接入 Claude Code、Codex、Cursor、Cline、Kilo Code 等常用 Agent 工具。

AllTokenAPI 同时提供 OpenAI 兼容、Anthropic Claude Messages 兼容和 Gemini 兼容接口。

大多数 Agent、IDE 插件、桌面客户端只要能自定义 Base URL、API Key 和 Model ID，就可以接入 TokenHub。

## 开始前准备
在配置任何工具之前，先准备好三样东西：

1. AllTokenAPI 工作台创建的 API Key。
2. AllTokenAPI  模型列表中的 Model ID，例如你准备用于聊天、代码、推理或快速补全的模型。
3. 工具支持的协议类型，常见类型是：
 - OpenAI Compatible
 - OpenAI Responses
 - Anthropic Claude Messages
 - Gemini Compatible。

建议先把密钥保存到本地安全位置。教程中的 `AllTokenAPI_API_KEY`为占位示例，实际填写时换成 AllTokenAPI 工作台生成的 Key。
